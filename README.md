# CLM: the open source alternative of Jev

## Introduction
------
CLM stands for Contrastive Language Model is the open source alternative of **Jev, which has not disclosed its architecture to public and Jev can only be accessed via API**. It uses a main message to be evaluated and contains a set of conditions that we want to evaluate and we also have to pass their values in case they have fixed categorical values they can assume and also shows the confidence scores for them.
It also allows simple boolean checks using **Noul**, just mention the condition and there would be a score between 0 and 1.
